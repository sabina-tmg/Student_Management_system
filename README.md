Steps to make this repo work in your local machine: 
Clone the repo → Create a virtual environment using `python -m venv myenv` 
→ Activate it with `myenv\Scripts\activate` (on Windows) 
→ Navigate to the `college_management_system` directory
→ Install dependencies using `pip install -r requirements.txt` 
→Run migrations with `python manage.py migrate` → Start the server using `python manage.py runserver`.
